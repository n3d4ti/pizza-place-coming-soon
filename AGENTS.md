## 📝 Code Style Guidelines

### HTML Structure
Follow semantic HTML5 practices:
```html
<!doctype html>
<html lang="hu">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Descriptive Title</title>
    <!-- Meta tags for SEO and social sharing -->
  </head>
  <body>
    <!-- Semantic content structure -->
  </body>
</html>
```

### CSS Organization
- **Embedded CSS**: Styles are embedded in `<style>` tag within HTML
- **Mobile-first**: Responsive design with min-width media queries
- **CSS Custom Properties**: Use for consistent theming
- **Animations**: CSS animations for loading and hover effects
- **Flexbox/Grid**: Modern layout techniques

### JavaScript Patterns
- **Vanilla ES6+**: No frameworks, pure JavaScript
- **Event-driven**: DOM event listeners for interactivity
- **Progressive enhancement**: Site works without JavaScript
- **Console logging**: Development debugging and analytics

### Naming Conventions
- **CSS Classes**: kebab-case (`.hero-section`, `.contact-card`)
- **IDs**: camelCase (`#loadingOverlay`)
- **JavaScript variables**: camelCase (`loadingOverlay`, `heroSection`)
- **File names**: kebab-case (`pizza-hero.jpg`)

### Responsive Design
- **Breakpoints**: 
  - Mobile: < 480px
  - Tablet: 480px - 768px
  - Desktop: > 768px
- **Font scaling**: clamp() for fluid typography
- **Touch-friendly**: 44px minimum touch targets

### Error Handling
- **Progressive Enhancement**: Site works without JavaScript
- **Image Fallbacks**: Graceful degradation for missing images
- **Console Logging**: Development debugging and user interaction tracking
- **404 Handling**: Implement custom error pages if needed
